# nixos-config

This repository defines the NixOS configuration and installer for the ThinkPad.
The flake lock pins Nixpkgs and Disko.

The [ThinkPad installation and recovery guide](docs/thinkpad-installation.md)
covers the encrypted disk layout, interactive account setup, rebuild, and
offline recovery.

The [ThinkPad hardware checklist](docs/thinkpad-hardware.md) covers physical
checks for the X1 Carbon Gen 9.

The [graphical session guide](docs/thinkpad-graphical.md) covers login,
terminal shortcuts, and TTY access.
